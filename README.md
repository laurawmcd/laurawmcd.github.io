# laurawalkermcdonald.com

Personal website, built with Jekyll and hosted free on GitHub Pages.

## Editing

- Home page text: `index.md`
- Contact page: `contact.md`
- Email, LinkedIn, site description: `_config.yml`
- Colours and fonts: the top of `assets/css/style.css`
- Menu and footer: `_layouts/default.html`

To edit on GitHub: open the file, click the pencil icon, make the change, click **Commit changes**. The live site updates within a minute or two.

## Images and files

Images live in `assets/images/`, the resume PDF in `assets/`. To add or replace one: open the folder on GitHub, click **Add file > Upload files**, drag the file in, click **Commit changes**. Keep the same file name to replace an existing image.
